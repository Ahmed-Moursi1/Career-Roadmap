# Student Management System

A command-line Python project built for Day 1 of my Backend Career Roadmap.

## Features
- Add students with name, age, and grades
- List all students
- Search by name (case-insensitive)
- Update student information
- Delete a student
- Calculate individual and class grade averages
- Validate user input

## Python concepts
Variables, strings, numbers, lists, dictionaries, conditions, loops, functions, parameters, return values, and basic validation.

## Requirements
- Python 3.10+
- No external packages

## Run
```bash
python main.py
```
On Windows, you can also use `py main.py`.

## Note
This beginner version keeps data in memory. Students are not saved after the program exits. File/database storage can be added in a later lesson.
